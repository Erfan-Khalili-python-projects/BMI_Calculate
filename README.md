# BMI_Calculate
# BMI Calculator 🧮

A simple BMI Calculator built with **Python**.

## Features

* Get user's weight and height
* Calculate BMI
* Show BMI category

## BMI Formula

```text
BMI = Weight / Height²
```

## Example

```text
enter you weight (kg): 70
enter you height (m): 1.75

bmi : 22.0
result:
Normal
```

## Technologies

* Python 3
* Functions
* Conditional Statements
* User Input
